# CLAUDE.md

Notes for working in this repo with Claude Code. **Start with `README.md`** — it
has the architecture, the build and deploy workflow, and the repo layout.

## Where things are

The site is in `new-live-site-design/`. Static pages are generated by the Python
builders in `new-live-site-design/_build/` from per-entry JSON under
`_build/content/`. Content is edited either in those files or through the Pages
CMS (`.pages.yml`). Pushing to the default branch rebuilds and deploys via GitHub
Actions — there is no manual deploy.

Build:

```bash
cd new-live-site-design/_build
python build_pages.py && python build_products.py && python build_services.py && python build_extra.py
```

## Conventions that must hold

- **Bilingual parity** — every page exists in English and Arabic; change both.
- **Arabic is a first draft** pending native review — flag new Arabic as unreviewed.
- **Brand teal** — never put text on `#00ACA1` (fails WCAG AA); text uses
  `#00776F`. Bright teal is logo / decoration only.
- **RTL** — logical CSS properties only; wrap Latin runs inside Arabic (brands,
  codes, numbers) in `dir="ltr"`.
- **Don't invent client facts** — certifications, CR / VAT, client relationships,
  and head-counts must be real; leave a `TODO` if unconfirmed.
- **Keep the three live-capture core pages** (`index`, `about-us`, `services`)
  faithful — enhance through the overlay, not by editing their bodies.
- After changing a generator, rebuild and confirm the generated HTML diff is only
  what you intended (the build is deterministic apart from the date-stamped
  `sitemap.xml` / `security.txt`).
