## RFQ back end

The catalogue front end is complete and posts this to `POST /api/rfq`:

```json
{ "contact": {"name","company","email","phone"},
  "project": "", "message": "",
  "lines": [{"sku","qty","note"}],
  "locale": "en|ar", "source": "web-catalogue" }
```
