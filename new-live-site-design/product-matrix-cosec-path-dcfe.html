Fingerprint Card Reader

Matrix card reader, part number COSEC PATH DCFE

MatrixOn order

COSEC PATH DCFE is a fingerprint-based access control device supporting up to 50,000 users and 500,000 event logs, Wi-Fi, Bluetooth (BLE), Ethernet, and PoE (IEEE 802.3af) for flexible network connectivity and easy installation, IP65-rated rugged design, high-accuracy fingerprint sensor (0.001% FAR), and supports fingerprint, mobile, and RFID card authentication
